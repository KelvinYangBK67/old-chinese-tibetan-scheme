上古漢語藏文轉寫方案

以藏文 Unicode 表示 Baxter–Sagart 上古漢語擬音。每個音節先解析為固定槽位，再由同一內部格式正向編碼或反向解碼。

B–S ↔ Tibetan開啟互轉工具

中間結構

MINOR + TIGHT + ROOT + CLASS + VOWEL + CODA + POSTCODA

minor = (C₁, vowel?, C₂?)
tight = (P₁?, P₂?)
class = (A/B, r, w)
coda  = ∅/j/w/r/m/n/ŋ/p/t/k/wk
post  = ∅/ʔ/s/ʔs

decode(encode(BS)) = normalize(BS)。反向恢復 canonical B–S，不恢復原始構擬標記。

B–S 正規化

* 刪除，[x]、(x)、<x> 均取 x；~ 預設取左側主形。minor 的點與 tight preinitial 的連字符保留為結構邊界。

P-rV 與 PrV 一律正規化為 root P 加 r-feature。因此 *s-rut 與 *srut 均寫作 སྲུད，反向輸出 srut。

Minor syllable

單輔音 minor：無明寫元音加 ྄，ə 加 ྀ，明寫 a i u e o 加 ཱ ི ུ ེ ོ。CC minor 寫作 BASE(C₁) + SUBJOIN(C₂) + vowel。點本身不輸出。

Tight preinitial

0: BASE(root)
1: BASE(P₁) + SUBJOIN(root)
2: BASE(P₁) + BASE(P₂) + SUBJOIN(root)

兩個 tight preinitial 時，P₁ 是裸前加位置；它不能攜帶元音符號。

逆轉規則

  1. 自右向左拆 postcoda。
  2. 按 longest match 拆 coda，優先匹配 ཝག。
  3. 拆主元音及八格 class。
  4. 由剩餘 stack 恢復零至兩個 tight preinitial 與 root。
  5. 最前帶 minor 元音或 ྄ 的 stack 恢復為 minor syllable。

人工資料表

清響音 m̥ n̥ ŋ̊ l̥ r̥ 不作字符級全局替換；須由漢字、詞義或 row ID 索引歷史來源。少數格式異常項另由 special normalization 表處理。漢字入口只使用明載於 han,bs CSV 的讀音，未收錄字不猜測。
